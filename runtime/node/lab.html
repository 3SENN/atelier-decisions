Process lab

connecting… Single questions: the playground
A process is a task written down once as small steps. Claude can set it up from your words, or it comes ready-made. Then only the decision model runs it: every step is one question it answers in a fraction of a second, a comparison done by code, or a control chosen by what it does. Whatever it isn't sure of goes to you.

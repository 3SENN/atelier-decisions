Add pictures, write the answers a question may have, and see which one the model picks and how sure it is. It never writes anything: it compares the picture with each answer’s own text. Atelier acts on a choice at 75%, a yes at 70% and a no at 30%; otherwise it keeps its rule. Nothing leaves this computer.
